# Supply Chain & Delivery Performance Analytics

## Project Overview
This project analyzes supply chain operations and delivery performance using Python. The goal is to understand delivery delays, sales trends, customer segments, and product performance through data analysis and visualization.

## Objectives
- Analyze delivery delays and shipping performance.
- Compare delivery performance across markets and regions.
- Identify sales and profit trends by product category.
- Analyze customer segments and order status.
- Create visualizations to communicate business insights.

## Dataset
**Dataset:** DataCo Smart Supply Chain Dataset

The dataset contains order, customer, product, sales, and shipping information.

Source: [DataCo Smart Supply Chain Dataset on Kaggle](https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis)

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Data loading and exploration
2. Data cleaning and preprocessing
3. Feature engineering for delivery delays
4. Exploratory Data Analysis (EDA)
5. Sales and delivery performance analysis
6. Data visualization
7. KPI summary and dashboard creation

## Key Analysis Areas
- Shipping mode performance
- Regional and market-wise delivery delays
- Product category sales and profit
- Monthly sales and order trends
- Customer segment analysis
- Order status and late delivery risk
